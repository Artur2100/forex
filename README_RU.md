# Forex Intelligence Agent v0.3 — бесплатный облачный MVP

## Назначение
Периодический облачный мониторинг через GitHub Actions. Компьютер пользователя может быть выключен. Уведомления отправляются в Telegram.

**Важно:** это исследовательский MVP, не профессиональный торговый советник и не гарантия прибыльных сделок. Сейчас доступны только технические предупреждения. Финальные торговые сигналы отключены до подключения проверенного экономического календаря, бэктеста и форвард-теста. Автоматической торговли нет.

## Что реализовано
- Наблюдение за EUR/USD, GBP/USD, USD/JPY, AUD/USD, USD/CAD, USD/CHF и фьючерсом на золото как приближением к XAU/USD.
- D1/H1 индикаторы EMA20/EMA50, RSI14, ATR14.
- Отдельные модули рыночных данных, технического анализа, новостей, макроконтекста, корреляций, риск-ориентиров и проверки допуска.
- RSS-публикации центральных банков: ФРС, ЕЦБ, Банка Канады и Резервного банка Австралии.
- Telegram-уведомления.
- GitHub Actions по расписанию раз в 15 минут.

## Ограничения
1. Yahoo Finance — сторонний источник, не котировки Альфа-Форекс. Возможны задержки, пропуски и отличия от исполняемой цены.
2. Для золота используется GC=F (фьючерс COMEX), а не спотовый XAU/USD.
3. GitHub Actions запускается периодически, это не постоянный процесс 24/7; cron может задерживаться.
4. RSS центральных банков не является полным новостным потоком или экономическим календарём.
5. Корреляционный модуль пока не валидирован и не используется как фильтр.
6. Уровни Entry/SL/TP в предупреждениях иллюстративные: не учитывают брокерский спред, комиссию, проскальзывание и спецификации контракта.
7. Финальные торговые сигналы намеренно заблокированы. Не использовать предупреждения как команду на открытие позиции.

## Первичная настройка
1. Создать Telegram-бота через @BotFather командой /newbot.
2. Открыть бота и нажать Start.
3. Получить chat_id через Telegram Bot API getUpdates (токен не публиковать).
4. В репозитории открыть **Settings → Secrets and variables → Actions** и добавить:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
5. Открыть **Actions → Forex Intelligence Scan → Run workflow** для тестового запуска.
6. Проверить, что сообщение пришло в Telegram.

Никогда не помещайте токен в код и не отправляйте его в чат. Если секреты ещё не добавлены, workflow не сможет отправлять уведомления.

## Настройки
- `fia/config.py` — инструменты, периоды, индикаторы и RSS.
- `fia/main.py` — оркестрация модулей.
- `.github/workflows/scan.yml` — расписание.
- `requirements.txt` — зависимости.
