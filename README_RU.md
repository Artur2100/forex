# Forex Intelligence Agent — облачный исследовательский MVP

## Назначение
Периодический мониторинг семи инструментов через GitHub Actions с уведомлениями в Telegram. Автоматической торговли и отправки ордеров нет.

**Это исследовательский инструмент, не финансовая рекомендация и не гарантия прибыльности.** Финальные торговые сигналы остаются заблокированы до проверки источников, календаря, бэктеста и форвард-теста.

## Инструменты и анализ
- EUR/USD, GBP/USD, USD/JPY, AUD/USD, USD/CAD, USD/CHF и XAU/USD.
- Для золота сначала запрашивается Yahoo Finance XAUUSD=X (spot proxy); при отсутствии свежих данных используется GC=F (COMEX futures proxy). Источник выводится в диагностике. Это сторонние котировки, не поток Альфа-Форекс.
- D1/H1: EMA20/EMA50, RSI14, ATR14, ADX14 и наклон быстрой EMA.
- Для H1 выбирается последняя полностью закрытая часовая свеча; текущая формирующаяся свеча не используется.
- Проверяется давность последней завершённой свечи. Для золота приоритет отдаётся свежему источнику; устаревший источник не маскируется под spot.
- ATR-уровни с модельным R:R 1:3 — ориентиры, не брокерские торговые уровни.

## Новости
- RSS официальных источников: ФРС, ЕЦБ, Банк Канады, RBA, Банк Англии, Банк Японии и релизы CPI/занятости BLS.
- Заголовки дедуплицируются, ограничиваются по давности и сортируются по приоритету.
- Классификация HIGH / MEDIUM / INFO / LOW и сопоставление тем с валютами/золотом.
- В Telegram выводятся приоритетные заголовки, число HIGH/MEDIUM и ошибки RSS.
- **RSS не является полноценным экономическим календарём.** Классификация по заголовкам — эвристика, не оценка фактического сюрприза относительно прогноза. Отсутствие новости в RSS не означает отсутствие события.

## Ограничения
1. Yahoo Finance — сторонний источник с возможными задержками, пропусками и расхождениями с брокером.
2. XAUUSD=X — сторонний spot proxy; GC=F — фьючерс COMEX. Не переносить их цены напрямую на график Альфа-Форекс.
3. GitHub Actions запускает периодические задания, а не постоянный сервер 24/7; cron может задерживаться или пропускаться.
4. RSS-источники могут менять формат, быть недоступны или публиковать неполные сведения.
5. ATR Entry/SL/TP не учитывают спред, комиссию, своп, проскальзывание, гэпы и спецификации инструмента у брокера.
6. EMA/RSI/ADX — фильтры, а не доказательство статистического преимущества.
7. Результаты журнала — гипотетические сетапы, не фактический P&L.
8. Не использовать предупреждение для входа без самостоятельной проверки котировки, свечи и риска.

## Структура
- fia/config.py — инструменты, интервалы, RSS и защитные настройки.
- fia/market_agent.py — загрузка котировок и проверка свежести.
- fia/technical_agent.py — индикаторы и выбор завершённых свечей.
- fia/news_agent.py — дедупликация, фильтрация и классификация новостей.
- fia/decision_agent.py — фильтры предупреждений.
- fia/risk_agent.py — модельные уровни.
- fia/main.py — оркестрация, журнал и Telegram.
- .github/workflows/scan.yml — тесты и расписание.
- tests/ — unit-тесты.

## Журнал
journal.csv хранит уникальные технические предупреждения. Это гипотетические сетапы, а не исполненные сделки.
- Условный вход — цена закрытия сигнальной H1-свечи.
- TP/SL проверяются по следующим H1 high/low.
- Если одна свеча задела TP и SL, исход помечается неоднозначным.
- По истечении семи дней без касания уровней запись истекает.
- Win rate считается только по однозначным TP/SL; издержки пока не моделируются.
